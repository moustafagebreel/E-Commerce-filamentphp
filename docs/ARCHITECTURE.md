# Project Architecture & System Design

## Overview
This full-stack E-Commerce web application is built with:
- **Backend Framework**: Laravel 10+
- **Admin Panel**: Filament 3.x
- **Frontend Interactivity**: Livewire 3.x & Alpine.js
- **Styling**: Tailwind CSS & Blade Layouts
- **Database**: MySQL / SQLite

## Core Subsystems
1. **Catalog Management**: Products, Categories, Brands, Variants, Reviews.
2. **Checkout & Cart**: Cookie-based CartService, Coupons, Orders, Status Tracking Logs.
3. **Customer Support**: Contact Inquiry Messages, FAQ Accordion.
4. **User Portal**: Address Book Management, Order History, Wishlist.
5. **REST API Layer**: Sanctum Authenticated endpoints with JsonResources.
